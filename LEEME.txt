DUELO PIXEL — PRIMERA INFRAESTRUCTURA DE SALAS ONLINE

QUÉ INCLUYE
- Interfaz para crear salas y entrar mediante un código de seis caracteres.
- Backend Cloudflare Worker + Durable Objects con WebSocket.
- Sala para dos personas, presencia, estado listo, selección de 8 criaturas y chat básico.
- Las salas expiran después de seis horas.
- Flujo de despliegue automático con GitHub Actions.

IMPORTANTE
Este primer hito implementa las salas, la conexión en tiempo real y la preparación de equipos. El combate todavía NO está sincronizado entre jugadores; el juego de combate actual sigue siendo local/contra IA. La siguiente fase es conectar las acciones y el estado del combate al servidor y validar cada turno en el servidor.

DESPLIEGUE GRATUITO
1. Crea una cuenta gratuita en Cloudflare.
2. Crea un repositorio de GitHub y sube el contenido de esta carpeta a la rama main.
3. En Cloudflare, crea un API Token con permisos para Workers Scripts (Edit) y Durable Objects (Edit), limitándolo a tu cuenta cuando sea posible.
4. En GitHub: Settings > Secrets and variables > Actions, crea CLOUDFLARE_API_TOKEN y CLOUDFLARE_ACCOUNT_ID. Nunca pongas esos valores dentro del HTML ni los compartas en el chat.
5. En Actions, ejecuta “Deploy Duelo Pixel”. El archivo wrangler.toml configura el Worker, Durable Object y la web estática.
6. Cuando termine, abre la URL workers.dev generada. En el menú Salas online, pega esa URL y pulsa Guardar URL.
7. Abre la web en dos navegadores/dispositivos y prueba crear una sala, entrar con el código, seleccionar ocho criaturas y marcar ambos jugadores como listos.

LÍMITES
- Está pensado para empezar en planes gratuitos; sujeto a los límites vigentes del proveedor.
- No requiere comprar un dominio.
- No uses ni publiques una clave service_role ni credenciales privadas.
